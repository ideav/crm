### Сравнение с прошлым замером B (`../run-20261023`)

| | B до | B после |
|---|---|---|
| T1 пробы, медиана из 11 | 11 (A 5/5) | 10 (A 0/5) |
| T1 ходы / токены / $ (медиана) | 181 / 169 896 / 1.5 | 55 / 79 741 / 0.5 |
| T1 итерации «проверка → правка» | 10 | 2 |
| T2 верно, медиана ходов, токенов | 50/50, 10, 24 074 | 50/50, 8.5, 22 270 |

Провал группы A во всех пяти сборках — одна причина. Агент добавил в «Договор» лишнюю колонку
«Компания» (ссылку на компанию) и повесил маску заявителя на неё, а не на цепочку
«Договор → Заявка → Компания». Юрист заполняет эту колонку руками, ТЗ её не знает. Поэтому
договор, заведённый по ТЗ (номер, заявка, сумма, дата, статус), заявитель не видит
(`T1.A2`, FALSE-DENY). Агенты сами отмечают это в ответах («если юрист не заполнит её,
заявитель такой договор не увидит»). В b-t1-5 отчёт «Остаток лимита» суммирует договоры по той же
колонке, отсюда ещё R1/S1/S2. Это решение агента, а не артефакт проб. Предусловие проб задаёт
договоры колонками из ТЗ; прежние тестовые договоры агента оно удаляет, как и в прошлом замере.
