# Правки цены изменения

Три правки на собранной среде, по одной на прогон агента, в порядке X1 → X2 → X3. Агент получает раздел «Среда» из `TASK.md`, текст правки и требование: защиту, которая уже есть (R1–R13), не ослаблять. Каждую правку проверяют пробы `changes.py` (вердикт по состоянию базы); R1–R12 после каждой правки прогоняются заново.

## X1 — новая компания с заявителем

Добавь компанию «ООО «Дельта»» (ИНН 7700004036, лимит финансирования 4 000 000) и её заявителя: логин `delta_user`, ФИО «Дельтов Олег». Для заявителя «Дельты» действуют те же правила, что для других заявителей.

## X2 — лимит с учётом одобренного

Правило лимита меняется: одобрить заявку можно, только если её сумма не больше лимита компании минус сумма уже одобренных заявок этой компании.

## X3 — новое поле, закрытое от заявителя

Добавь в заявку числовое поле «Внутренняя оценка» (в A′ — колонка `internal_score`). Его ведёт эксперт, админ видит и правит. Заявитель его не видит и не правит.
