# Гайд пользователя: сопоставление каталогов

## На пальцах

Обычный рабочий цикл состоит из пяти действий:

1. загрузить обновлённые каталоги;
2. разметить новые токены — что товар, что марка, что модель;
3. нажать «Старт» в массовом подборе;
4. проверить спорные пары;
5. выгрузить результат.

Настройки категории, колонок и весов делает внедренец. Пользователю не нужно открывать конструктор или менять запросы.

## Операции

### 1. Загрузите файлы

Откройте рабочее место загрузки и выберите сохранённую настройку, которую подготовил внедренец. Проверьте:

- выбран правильный лист;
- число распознанных строк похоже на число строк в файле;
- первая строка данных не попала в заголовок и наоборот;
- колонки «Наименование» и «Артикул» заполнены ожидаемыми значениями.

Запустите загрузку. После неё выполните сохранённые запросы токенизации для RFP и SKU, если внедренец не включил этот шаг в загрузку.

### 2. Разметьте новые токены

Откройте «Разметка токенов». Здесь список слов, на которые разобраны наименования, — сверху те, что встречаются чаще всего. Отметьте у каждого, чем оно является: товаром («картридж», «дрель»), маркой («HP», «Bosch») или моделью («280», «GSB13»). Флажок «Только неразмеченные» оставляет то, что появилось после последней загрузки.

Зачем: если у заявки и позиции каталога совпали и товар, и марка, и модель — пара помечается признаком ТММ и поднимается в подборе. Без разметки подбор считает только число общих слов и чаще путает похожие позиции.

Размечать весь список не нужно: начните сверху и остановитесь, когда пойдут редкие слова. Изменения сохраняются одной кнопкой.

### 3. Запустите массовый подбор

Откройте «Массовый подбор».

1. При необходимости введите ключевое слово, чтобы обработать часть каталога.
2. Оставьте флажок «Авто»: система сама меняет число потоков по скорости пачек.
3. Нажмите «Старт».
4. Следите за показателями «обработано», «с подбором», «без подбора» и «ошибки».

«Стоп» останавливает выдачу новых задач. Уже запущенные запросы завершаются безопасно.

### 4. Проверьте спорные пары

Откройте «Ручное сопоставление», найдите строку RFP и выберите её. Справа появятся кандидаты SKU.

- «Принять» записывает выбранный артикул и фиксирует решение в истории.
- «Отклонить» фиксирует, что этот SKU не нужно предлагать для той же строки снова.
- «Доуточнить серую зону» доступно только если внедренец включил ИИ и в настроенном диапазоне есть кандидаты.

ИИ показывает рекомендацию и причину, но не заменяет ручное подтверждение. Если ИИ недоступен, ручные кнопки и весь основной процесс продолжают работать.

Принятое вручную решение сохраняется при повторном массовом прогоне, а отклонённый SKU не должен снова появляться для той же строки RFP.

Раскройте «История решений по этой позиции», если нужно понять, кто и когда проверял пару.

### 5. Выгрузите результат

Откройте «Выгрузка результата».

- «Excel» скачивает текущие строки отчёта `matching_export`.
- «JSON» скачивает тот же результат вместе с версией формата и временем выгрузки.
- В блоке «JSON API для интеграции» показан адрес для внешней системы.

Пустой отчёт не создаёт пустой или битый файл. Сначала завершите подбор, затем нажмите «Обновить».

## Что означает результат

| Поле | Значение |
|---|---|
| `Наш артикул` | Лучший выбранный SKU или принятый вручную артикул |
| `Кандидаты` | Другие подходящие SKU, которые стоит проверить |
| `Точность подбора` | Объяснимая оценка токенов, артикула и настроенных атрибутов |
| `ИИ-вердикт` | Необязательная рекомендация ИИ по короткому спорному списку |

Высокая точность не отменяет проверку критичных позиций. Обязательные атрибуты отсеивают явные расхождения до расчёта оценки.

## Грабли

- Строки со значением `0` в «Наш артикул» обработаны, но совпадение не найдено. Передавайте их внедренцу для анализа правил.
- Если одни и те же строки возвращаются после каждого прогона, сообщите внедренцу: вероятно, результат не записывается или нет гранта.
- Не исправляйте артикулы прямо в экспортированном файле как единственный источник истины. Примите решение в рабочем месте, затем выгрузите заново.
- Не отправляйте весь каталог в ИИ. Кнопка работает только с уже отобранной серой зоной.
- Если Excel и JSON различаются, зафиксируйте время, фильтр и имя отчёта, затем остановите передачу результата до проверки.
