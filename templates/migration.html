Миграция конфигурации базы

Экспорт функционала текущей БД в JSON и развёртывание на другом инстансе. Выгружаются неслужебные таблицы с данными, шаблоны и скрипты, запросы, пользователи и пункты меню. Служебными считаются объекты с ID меньше порога. Доступно только роли admin.

1. Экспорт конфигурации

Переносятся: таблицы с подписями и свойствами колонок, ссылками и подчинёнными таблицами, их записи, запросы со всеми полями колонок (фильтры, функции, форматы, «скрыть», сортировка, SET). Не переносятся: роли и их права, пароли пользователей, служебные объекты с ID ниже порога. Пользователь получает роль по её ID в базе-приёмнике.

2. Импорт / развёртывание

Термины переиспользуются, если свободны; занятые получают суффикс, чтобы не было конфликта имён и полей. Пароли не переносятся — импортированным пользователям нужно задать пароль.

3. Откат последнего импорта

Импорт ещё не выполнялся в этом браузере.
Удаляются все объекты и записи с ID ≥ ID первого созданного при импорте — записи, затем колонки, затем типы; несколько циклов с корректной обработкой ссылок (останов, если цикл ничего не удалил или циклов больше 100). Перед таблицей снимается её ref-тип (referenced), если он создан этим же импортом.
