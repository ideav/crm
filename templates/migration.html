Миграция конфигурации базы

Экспорт функционала текущей БД в JSON и развёртывание на другом инстансе. Выгружаются неслужебные таблицы с данными, шаблоны и скрипты, запросы, пользователи и пункты меню. Служебными считаются объекты с ID меньше порога. Доступно только роли admin.

1. Экспорт конфигурации

Переносятся: таблицы с подписями и свойствами колонок, ссылками и подчинёнными таблицами, их записи, запросы со всеми полями колонок (фильтры, функции, форматы, «скрыть», сортировка, SET), роли с правами на объекты и пунктами меню. Не переносятся: пароли пользователей, служебные объекты с ID ниже порога. Служебная роль пользователя (ID ниже порога) берётся по ID, перенесённая — по новому ID.

2. Импорт / развёртывание

Установка: термины переиспользуются, если свободны; занятые получают суффикс, чтобы не было конфликта имён и полей. Обновление: таблица, колонка, запрос, роль и пункт меню с тем же именем обновляются на месте, недостающие добавляются; записи пакета попадают только в новые таблицы, записи базы не трогаются; колонки и таблицы, которых нет в пакете, остаются; смена типа колонки не выполняется и отмечается в журнале. В файлах экранов имя базы-источника и ID её таблиц, колонок и запросов заменяются на здешние, каждая замена — в журнале. Пароли не переносятся — импортированным пользователям нужно задать пароль.

3. Откат последнего импорта

Импорт ещё не выполнялся в этом браузере.
Удаляются все объекты и записи с ID ≥ ID первого созданного при импорте — записи, затем колонки, затем типы; несколько циклов с корректной обработкой ссылок (останов, если цикл ничего не удалил или циклов больше 100). Перед таблицей снимается её ref-тип (referenced), если он создан этим же импортом. Сначала возвращаются прежние значения изменённых объектов (свойства колонок, реквизиты запросов, прав и меню) и прежнее содержимое перезаписанных файлов; файлы, которых до импорта не было, удаляются.
