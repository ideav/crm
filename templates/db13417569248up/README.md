## Деплой правок (без SSH, через API панели)

```bash

curl -H "X-Authorization: <token>" "https://ideav.ru/db13417569248up/xsrf?JSON=1"
# 2) залить файл (rewrite перезаписывает; add_path — подпапка /js или /css)
curl -X POST -H "X-Authorization: <token>" \
  "https://ideav.ru/db13417569248up/dir_admin?download=1&JSON=1&rewrite=1&add_path=/js" \
  -F "upload=1" -F "_xsrf=<xsrf>" -F "f=@pf-plan.js;filename=pf-plan.js"
# 3) скачать текущий файл с сервера
curl -H "X-Authorization: <token>" \
  "https://ideav.ru/db13417569248up/dir_admin?templates=1&gf=pf-plan.html&JSON=1"
```

`download/` публично читается: `https://ideav.ru/download/db13417569248up/js/pf-plan.js`
(кэш браузера гасится `?{_global_.version}` в обёртках).

## API-заметки

- Чтение записей: `GET /object/<typeId>/?JSON_OBJ&LIMIT=0,1000` (не просто `?JSON=1` — это схема).
- Создание записи: `POST /_m_new/<typeId>` c `t<typeId>=имя`, `_xsrf`, `up`.
- Все пишущие вызовы требуют `_xsrf` из `GET /xsrf?JSON=1` (заголовок `X-Authorization`).
- Новая колонка: `POST /_d_new` (t=<тип поля>, val=имя) → `_d_req/<tableId>` t=<typeId>.
